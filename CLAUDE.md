# Project Overview
## Stack
- Next.js
- TypeScript
- Clerk Authentication
- PostgreSQL
- Drizzle ORM
## Project
Multi-tenant salon booking SaaS.
## Rules
- Never replace Clerk.
- PostgreSQL is the source of truth.
- Google Calendar is sync only.
- Always use repositories/services.
- Never query the database directly from UI components.
- Keep everything strongly typed.
- Prioritize clean architecture over quick fixes.
